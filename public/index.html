ℹ️ Discord OAuth2 Setup Required

Add DISCORD_CLIENT_SECRET to your .env file to enable Discord Login.

  1. Go to Discord Developer Portal
  2. Select your Bot App (ID: 1544714586756751534)
  3. Navigate to OAuth2
  4. Under Redirects, click Add Redirect:
    http://localhost:3000/api/auth/discord/callback
  5. Reset or copy your Client Secret
  6. Add to .env: DISCORD_CLIENT_SECRET=your_secret_here
  7. Restart the bot server
